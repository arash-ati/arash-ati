## 👋 About Me

Hi, I'm **Arash Taravati**, a Frontend Developer specializing in Angular, TypeScript, and modern web application development.

I have professional experience building responsive web applications, interactive dashboards, reusable UI components, and business-oriented digital products.

My experience includes working on public transportation platforms, industrial portals, administrative dashboards, e-commerce websites, and WordPress-based solutions.

I focus on translating business requirements into maintainable technical solutions while paying attention to user experience, application architecture, performance, and code quality.

Beyond development, I also have experience in project operations, Agile methodologies, Scrum practices, and coordinating cross-functional teams.

### What I Do

- Develop modern web applications using Angular and TypeScript.

- Integrate RESTful APIs and interactive maps.

- Develop and customize WordPress and WooCommerce websites.
- Collaborate with teams using Scrum, Jira, and Confluence.
